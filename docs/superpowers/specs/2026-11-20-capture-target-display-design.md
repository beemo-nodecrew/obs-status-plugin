# 녹화 화면·마이크 이름 표시 설계

2026-11-20

## 목적

- 지금 녹화되는 화면(모니터)과 마이크의 이름을 오버레이 캡슐에 항상 표시
- 이유: 서브 모니터 연결이 끊겼다가 다시 붙으면 OBS 디스플레이 캡처의 모니터 설정이 풀려 "찾을 수 없음"이 되고 검은 화면이 녹화됨. 녹화 상태는 정상으로 보여 녹화 중에 알아챌 수 없음
- 성공 기준: 모니터 설정이 풀리면 캡슐의 화면 이름이 `찾을 수 없음`으로 바뀌어 강사가 바로 알아봄

## 범위

포함

- 설정 창에서 디스플레이 캡처 소스 하나를 고르고, 그 소스가 캡처 중인 모니터 이름을 캡슐에 표시
- 이미 설정된 마이크 소스가 실제로 잡고 있는 장치 이름을 캡슐에 표시
- 모니터·장치를 찾지 못하면 이름 자리에 `찾을 수 없음` 표시

제외

- 현재 장면에서 캡처 소스를 자동으로 찾기 (사용자가 설정 지정 방식을 선택)
- 별도 경고(빨간 테두리, 소리 등)와 캡처 설정 자동 복구
- 창 캡처·게임 캡처 소스

## 제약

- 오버레이는 강사만 보는 메인 모니터에 표시되므로 캡슐 길이에 교육생 노출 고려는 필요 없음
- 대상 OS Windows. 다른 OS는 CI 빌드만 깨지지 않으면 됨
- 기존 캡슐 디자인(어두운 캡슐, 상태색, 구분선)과 같은 모양을 유지

## 검토한 방식

| 방식 | 장점 | 단점 | 결정 |
| --- | --- | --- | --- |
| 현재 장면에서 자동 탐지 | 설정 불필요, 장면 전환을 따라감 | 소스가 여러 개면 이름이 여러 개, 구현 복잡 | 채택 안 함 |
| 설정 창에서 캡처 소스 지정 | 구현이 단순, 항상 한 개 표시 | 장면·소스를 바꾸면 다시 지정 필요 | **채택 (사용자 선택)** |

표시 방식은 "평소 아이콘 + 문제 시 경고", "항상 이름 표시", "둘 다" 중 **항상 이름 표시**를 사용자가 선택

## 동작

### 캡슐 모양

```
● 녹화 중 00:12:34 │ 🖥 DELL U2720Q │ 🎤 USB 마이크
```

- 화면 구간: 모니터 아이콘 + 이름. 캡처 소스를 지정하지 않으면 구간 자체를 숨김
- 마이크 구간: 기존 마이크 아이콘(음소거 사선·초록 점 그대로) 오른쪽에 장치 이름
- `찾을 수 없음`은 빨간색(기존 `kRecRed`)으로 표시
- 이름이 길면 최대 24자 정도에서 `…`로 줄임

### 화면 이름 얻기

- 지정한 소스의 `obs_source_properties`에서 모니터 목록 속성(Windows `monitor_capture`의 `monitor_id`)을 읽고, 소스 설정의 현재 값과 같은 항목의 표시 문구를 사용. OBS 속성 창에 보이는 문구와 같음
- `DELL U2720Q: 2560x1440 @ 1920,0` 같은 문구는 `:` 앞부분만 사용
- `찾을 수 없음` 조건: 목록에 현재 값이 없음, 또는 소스 가로·세로 크기가 0, 또는 지정한 소스가 없음(삭제됨)

### 마이크 이름 얻기

- 마이크 소스의 속성 중 장치 목록(`wasapi_input_capture`의 `device_id`)에서 현재 값과 같은 항목의 표시 문구를 사용
- 장치 목록에 없으면 `찾을 수 없음`
- 장치 목록 속성이 없는 소스 종류면 OBS 소스 이름을 대신 표시

### 다시 읽는 시점

- 설정 적용, 지정 소스의 `update` 시그널, 모니터 추가·제거(`screenAdded`/`screenRemoved`), 장면 컬렉션 변경
- 놓치는 경우에 대비해 2초 주기 재확인
- 소스 시그널은 다른 스레드에서 오므로 기존 마이크 처리처럼 메인 스레드로 넘겨 처리

### 설정

- 설정 창에 `녹화 화면 소스` 콤보 박스 추가 (`없음` + `monitor_capture` 소스 목록). 마이크 소스 행 위에 둠
- 설정 파일에 `capture_source`(소스 이름) 저장. 기존 마이크처럼 소스 이름 변경을 따라가 저장값 갱신
- 문구는 `en-US.ini`, `ko-KR.ini`에 추가

## 빌더에게 맡기는 부분

- 화면 이름 추적 클래스 구조 (기존 `MicMonitor`와 비슷한 별도 클래스 권장)
- 아이콘 그리기 세부, 줄임 길이, 간격 수치
- 2초 재확인이 OBS 성능에 영향을 주면 주기 조정
- `monitor_id` 대신 예전 `monitor`(정수) 설정을 쓰는 구버전 OBS 대응 여부

## 실기 확인 항목

- 서브 모니터 케이블 분리 → 재연결 후 OBS 속성 창이 "찾을 수 없음"일 때 캡슐도 `찾을 수 없음`으로 바뀌는지
- 그때 소스 크기가 실제로 0이 되는지 (로그로 확인)
- 마이크 장치 분리 시 `찾을 수 없음`으로 바뀌는지
- 2초 재확인 중 OBS 프레임 드롭이 없는지
